# L


## Lambda

AWS Lambda, the serverless compute service used by the AWS provider for trusted handlers, backend operations, and event-driven integrations.


## Layout

The reusable route skeleton that provides shared structure such as headers, content containers, footers, providers, feedback, and loading behavior. Route layouts bootstrap once and pass the resolved context through the CloudIgniter wrapper chain.


## Locale

The resolved language/region identifier used for messages, formatting, and document metadata. It is resolved on the server and must produce deterministic initial rendering.

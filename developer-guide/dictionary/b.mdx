# B


## Backend Manifest

A package-owned declaration of backend modules, functions, tables, bindings, and policy requirements. The template projects active manifest entries into concrete Amplify resources and rejects ownership collisions.


## Bootstrap

The trusted server process that resolves the current CloudIgniter context before layouts and pages render. It brings together configuration, request context, settings, identity, roles, environment mode, and provider status. See [The Bootstrap](/docs/core-system/bootstrap).


## Bounded Context

A security and operational ownership boundary used to group related data and behavior. CloudIgniter chooses DynamoDB table boundaries by access patterns, lifecycle, IAM exposure, traffic, and failure isolation—not merely by entity type.

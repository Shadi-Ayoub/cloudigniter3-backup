# P


## Page Client Wrapper

The browser-side composition for an interactive route experience. It receives serializable server-resolved input and assembles page-specific UI, state, events, and feedback inside supported CloudIgniter client boundaries.


## Page Component

The reusable CloudIgniter page-content shell represented by `CiPage`. It owns page scrolling, breadcrumbs/header presentation, loading, message scope, layout-aware sizing, and client instrumentation.


## Permission

The resource/action capability requested or matched during authorization. A privilege supplies an allow or deny effect for one or more permission patterns within an applicable scope.


## Precedence

A conflict-ordering value for roles; a lower number is stronger. Precedence does not create role inheritance or expand assignment scope.


## Predecessor

An Org Unit ancestor stored in authoritative root-to-parent order. Predecessor IDs drive paths, hierarchy display, subtree moves, and descendant authorization.


## Privilege

A stable allow or deny rule attached to a role or directly to a subject. It describes resource/action matching and carries a human-readable title for administration and audit evidence.


## Provider

An implementation that adapts generic CloudIgniter contracts to external infrastructure or services. Provider-specific details remain outside `@cloudigniter/core`.


## Proxy

The thin application request entry point that delegates reusable Next.js routing and context handling. It removes untrusted incoming context, resolves tenant and Org Unit information, matches the logical route, and forwards authoritative same-request context.


## Purge

The irreversible removal of a soft-deleted resource and its owned participants. Purge is a separately authorized Trash-only action requiring fresh confirmation, a reason, and trusted state validation.

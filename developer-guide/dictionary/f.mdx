# F


## Feature Pathname

The logical application pathname after CloudIgniter removes public tenant and Org Unit transport segments. Route matching uses this value; for example, `/t/acme/division/dashboard` may resolve to `/dashboard`.


## Framework Integration

The layer that adapts generic CloudIgniter contracts to a web framework. `@cloudigniter/next` owns Next.js request handling, context transport, routing, rendering integration, and provider orchestration.

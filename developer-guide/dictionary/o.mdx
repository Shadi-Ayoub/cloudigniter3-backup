# O


## Operational Status

A reversible state such as active, suspended, or archived that controls ordinary operation without deleting the resource. It remains separate from deletion state so Restore does not silently change the prior status.


## Org Unit

A node in a tenant-aware organizational tree. An Org Unit has a stable identity, one parent, authoritative predecessor IDs, an immutable slug, and one or more tenant attachments. See [Org Unit Management](/docs/core-system/multi-Tenancy/org-unit-management).


## Org Unit Attachment

An authoritative tenant/path projection that connects one canonical Org Unit to a tenant and supports direct routing lookup. Sharing is represented by several attachments to the same canonical node.


## Org Unit Explorer

The two-panel management UI that displays Org Unit trees beside the focused node’s details. It supports filtering, context actions, tenant attachments, resizing, RTL placement, and confirmed subtree moves.

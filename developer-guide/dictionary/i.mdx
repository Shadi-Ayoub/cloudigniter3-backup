# I


## Identity Provider

A service that authenticates identities and supplies claims or group memberships. Provider data is assignment input; it is not proof that an arbitrary tenant or Org Unit scope is valid.


## Immutable Slug

A stable, URL-safe Org Unit segment that cannot be changed after creation. Moving an Org Unit rewrites its path and descendants while retaining the node’s slug and identity.


## Internationalization

The localization system that resolves locale, text direction, and route-scoped message bundles. Application messages override core messages at matching keys. See [Internationalization](/docs/internationalization/intro).

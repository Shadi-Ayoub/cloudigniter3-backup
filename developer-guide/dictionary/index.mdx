# CloudIgniter Dictionary

Use this dictionary when a CloudIgniter guide, API, or interface uses a platform-specific term. The left panel groups terms by their first letter and alphabetizes the terms inside every group.

Inside the guides, linked Dictionary terms open a viewer over the current page. The viewer offers the complete alphabet and term search while reusing these same definition files. Select the book icon beside the **Dictionary** tab to open the viewer directly from any guide page, or use the tab when you want the full-page browsing experience.

Definitions are intentionally concise. Follow the linked guides when you need implementation rules, examples, or API details.

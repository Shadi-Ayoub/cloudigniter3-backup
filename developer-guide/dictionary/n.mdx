# N


## NEW Badge

A shared, time-limited badge displayed for recently created resources. Recency is calculated from `createdAt` using the Core-owned default duration, so refreshing does not restart the badge.


## Next.js Integration

The framework-specific CloudIgniter layer in `@cloudigniter/next`. It owns proxy behavior, request context, route rewrites, server/client wrappers, Next.js adapters, and selected-provider orchestration.

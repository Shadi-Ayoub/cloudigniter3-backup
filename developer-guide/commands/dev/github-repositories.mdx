List configured source, build, and public repository destinations.

## Syntax

```text
dev github repositories [--json]
```

## Prerequisites

Run in the private workspace with the relevant company policies configured. This local command does not require GitHub CLI or authentication.

## Parameters

| Parameter | Meaning |
| --- | --- |
| `--json` | Accepted; output is structured JSON. |

See the [dev common options](./index.mdx#common-options) for workspace selection, diagnostics, help, and version output.

## Remarks and effects

Reads the repository inventory locally. It does not create repositories or verify their remote state.

## Examples

```bash
pnpm exec dev github repositories --json
```

## Errors and recovery

Invalid or missing repository inventory fails validation.

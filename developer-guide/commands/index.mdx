## ci Commands

Application developers and operators use `ci` from `@cloudigniter/cli` to validate modules, edit Data Entity resources, and manage Amplify bootstrapping and sandbox deployment.

[Browse ci Commands A–Z](./ci/index.mdx)

```bash
pnpm exec ci --help
```

## dev commands

CloudIgniter maintainers use the private `dev` toolkit for package builds, testing, quality checks, GitHub workflows, template exports, and reviewed release delivery.

[Browse dev commands A–Z](./dev/index.mdx)

pnpm exec dev --help

## Reading command syntax

- Square brackets indicate optional input.
- Angle brackets indicate a value to replace; do not type the brackets.
- A vertical bar separates alternatives.
- Examples use `pnpm exec` to resolve the installed executable without requiring a global install.
- Commands that change files, cloud resources, or remote repositories describe those effects in **Remarks and effects**. Use a preview flag only when that command documents one.

CloudIgniter has two developer profiles. A **CloudIgniter User** builds and operates
applications with the platform. A **CloudIgniter Developer** maintains the platform
itself and the tools used to build, test and release it.

| Profile | Tool | Package | Scope |
| --- | --- | --- | --- |
| CloudIgniter User | **`ci`**, the CloudIgniter CLI | Public `@cloudigniter/cli` | Application resources, modules and supported provider operations. |
| CloudIgniter Developer | **`dev`**, the CloudIgniter Developer Toolkit (DEV) | Restricted `@cloudigniter/dev` | Company package maintenance, quality, template preparation and reviewed releases. |

A company developer can also use `ci` while working on an application. Choose the
tool by the work being performed: application operations belong to `ci`; maintaining
CloudIgniter packages and company delivery workflows belongs to `dev`.

These profiles describe development responsibilities. Application role IDs and
GitHub/npm permissions are configured separately; choosing an executable does not
grant access.

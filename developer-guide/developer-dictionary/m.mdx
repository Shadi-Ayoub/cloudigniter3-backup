## MDX {#mdx}

The Markdown-and-JSX format used for many CloudIgniter guide pages. Dictionary letter pages are MDX sources rendered both as full pages and inside the Dictionary Viewer. Keep definitions under level-two headings with stable anchors so both views identify the same section.

## Monorepo {#monorepo}

A repository containing several related packages and applications. The CloudIgniter workspace includes reusable packages under `packages`, application composition under `apps`, and the documentation site under `developer-guide`. Sharing a repository does not remove package ownership or public import boundaries.

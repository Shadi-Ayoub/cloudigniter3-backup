## Source Repository {#source-repository}

A repository holding the source snapshot reviewed for a CloudIgniter package or application release. The company’s paired delivery workflow distinguishes reviewed source from archives and workflows in a build repository. See [GitHub and npm publishing](/company-developers/tooling/github-npm-publishing).

## Staged Archive {#staged-archive}

An exact npm package archive prepared for review and later delivery. The company workflow checks the archive’s identity and approved source rather than silently rebuilding a different artifact for publication. Staging an archive is not final registry publication. See [GitHub and npm publishing](/company-developers/tooling/github-npm-publishing).

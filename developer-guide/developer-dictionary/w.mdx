## Workspace Protocol {#workspace-protocol}

The `workspace:` dependency notation used to refer to a package in the local pnpm workspace. CloudIgniter uses local links during development. A standalone public template export replaces relevant workspace references with the intended public package versions. See [template export](/company-developers/tooling/template-export).

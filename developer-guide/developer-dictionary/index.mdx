The **Developer Dictionary** defines the implementation, tooling, and technology terms used by CloudIgniter company developers. Its green accents distinguish it from the blue [user Dictionary](/dictionary).

The developer documentation extends the user documentation: use the user Dictionary for shared platform concepts and this dictionary for contributor terminology. Internal definitions have their own catalog, routes, and viewer search.

Select the green book icon beside **Developer Dictionary** to open the viewer without leaving your current page. Search for a term or browse by letter; the viewer and full pages use the same definitions. Linked internal terms in the Developer guide and dev command manuals open this viewer automatically.

# Tenants Management in CloudIgniter

CloudIgniter is designed as a **multi-tenant platform by default**, enabling a single deployed system to securely
serve multiple organizations (companies, schools, departments, institutions, or environments) while maintaining
strong isolation, scalability, and extensibility.

This document explains:

- Core tenant concepts and definitions
- The tenant data model and lifecycle
- DynamoDB table structure and access patterns
- Strategies used for isolation, scoping, and extensibility
- Seeding tenants for demos and testing
- Practical examples for developers

# What Is a Tenant?

In CloudIgniter, a **Tenant** represents a logical organization boundary.

A tenant may correspond to:

- A school
- A campus
- A department
- A customer organization
- A sandbox or test environment

Every tenant has:

- A unique identifier
- Its own configuration scope
- Its own users, roles, and permissions
- Its own operational state (active, suspended, archived)

> **Key Principle:**  
> Nothing in CloudIgniter is “global by accident.” If data is not explicitly global, it is tenant-scoped.

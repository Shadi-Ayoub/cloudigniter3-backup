# Core Tenant concepts

## Tenant identity

A Tenant has a stable identifier and a routing slug. The identifier is used for domain records and authorization
scope. The slug is the browser-facing name used by the selected routing mode. Keep the resolved canonical identity
when calling trusted operations; do not substitute a browser-entered ID or a pathname segment.

## Tenant scope

The request may have `system`, `global`, or `tenant` scope. Scope is separate from the actor's permissions and
from descriptive Tenant metadata. See [Tenant scope](./core-concepts/tenant-scope) for examples and route restrictions.

## Tenant status

Tenant operational statuses are `active`, `suspended`, and `archived`. Status describes operational state;
its enforcement depends on the relevant route and service policy. The template exposes Tenant validation and
information-page configuration, so check the effective configuration rather than assuming every lookup enforces it.

Deletion is a separate lifecycle overlay. A suspended Tenant restored from Trash remains suspended; restoration
does not grant access or activate it. Follow [Tenant lifecycle operations](./lifecycle-operations).

## Org Unit trees

An Org Unit has a canonical identity, parent relationship, slug, path, and Tenant attachments. Several Tenants can
share the same canonical node or subtree. Each child's Tenant set must be contained by its parent's Tenant set.

The authoritative predecessor IDs run from the root to the direct parent. Descendant authorization uses that
stored chain together with the current Tenant ID. Sharing a node does not allow a grant in one Tenant to cross
into another. See [Org Unit management](./org-unit-management).

## Tenant type

Tenant type is descriptive application metadata. It does not replace route scope, environment mode, or a scoped
permission assignment. Use separate development, test, staging, and production deployments for environment isolation.

Continue with [Tenant scope](./core-concepts/tenant-scope) and [routing modes](./configuration/routing-modes).

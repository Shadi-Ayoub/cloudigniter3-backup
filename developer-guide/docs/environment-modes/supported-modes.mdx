---
title: Supported modes
description: The canonical CiEnvMode values and their intended use.
sidebar_position: 2
---

```ts
export type CiEnvMode =
  | "development"
  | "test"
  | "staging"
  | "production";
```

| Mode | Purpose | Developer tools |
| --- | --- | --- |
| `development` | Local or explicitly disposable application development | Eligible after authentication and exact `developer` role checks |
| `test` | Automated test execution | Denied |
| `staging` | Production-like validation | Denied |
| `production` | Live application operation | Denied |

`test` is deliberately not a developer-tools bypass. Tests should invoke focused functions with explicit test
fixtures or exercise a development deployment; they must not make deployed mutation handlers broadly available.

Use these exact values in environment files and application configuration. A deployment label such as
“sandbox” does not change the accepted `CiEnvMode` values.

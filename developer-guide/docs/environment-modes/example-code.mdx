title: Environment-mode recipes
description: Use the public developer-tools access gate correctly.
sidebar_position: 7
---

```ts
import { ciCanAccessDeveloperTools } from "@cloudigniter/core/lib";

const allowed = ciCanAccessDeveloperTools({
  envMode: context.env.mode,
  actor: {
    authenticated: context.auth.user.authenticated,
    roles: context.auth.user.roles,
  },
});
```

Use the result to compose presentation. A mutation must call the same helper again with fresh trusted context,
and the provider handler must independently require `CI_ENV_MODE === "development"` plus exact Cognito group
membership.

Do not branch authorization on `process.env.NEXT_PUBLIC_CI_ENV_MODE`; that value is delivered to the browser and
is not trustworthy evidence.

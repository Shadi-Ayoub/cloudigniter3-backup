- CloudIgniter modes are `development`, `test`, `staging`, and `production`.
- Deployment resources, not key suffixes, provide environment isolation.
- Developer features require development mode, an authenticated actor, and exact `developer` membership.
- Client visibility never replaces server and provider authorization.
- Seeded resources carry explicit provenance and are collected through bounded marker queries.

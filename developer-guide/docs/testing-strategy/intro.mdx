# Introduction

CloudIgniter provides a fully isolated, safe-by-design testing system that lets
developers run automated tests, manual tests, and mock data scenarios **without
ever risking production (live) data**.

This section explains:

- How testing ties into **environment modes**
- How test data is separated at the **Table** level
- The **helpers and tools** you should use (not re-implement)
- How **Amplify handlers** and **Next.js client components** should behave
- Recommended E2E testing workflows and best practices

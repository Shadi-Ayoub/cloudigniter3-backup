Runtime-neutral helpers include:

- [`ciCanAccessDeveloperTools`](./ci-can-access-developer-tools) for the strict shared developer-capability gate.
- [AppSync AWSJSON helpers](./ci-aws-json) for encoding GraphQL variables and decoding provider responses.
- [`ciBuildTableKey`](./ci-build-table-key) and [`ciBuildTableKeys`](./ci-build-table-keys) for canonical persisted keys.
- [`ciIsNewResource`](./ci-new-resource) and `CI_DEFAULT_NEW_RESOURCE_BADGE_DURATION_MS` for shared resource-recency behavior.

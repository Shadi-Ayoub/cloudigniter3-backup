# CloudIgniter API Reference

The **CloudIgniter API Reference** documents the complete public programmatic
interface of the CloudIgniter framework.

This section serves as the authoritative reference for developers building
CloudIgniter applications and extensions. It describes **what the system
provides**, **how each API behaves**, and **how it is intended to be used**.

---

## What “API” Means in CloudIgniter

In CloudIgniter, the term **API** refers to the full set of **public,
stable programmatic interfaces** exposed by the framework, including:

- Utility functions
- Hooks and helpers
- Server-side runtime APIs
- Client-side APIs
- Shared client/server utilities
- Type definitions and contracts

This is **not limited to HTTP or GraphQL endpoints**.

---

## What This Section Covers

The API Reference includes:

- **Client APIs**

  - React hooks
  - Navigation helpers
  - UI and state utilities

- **Server APIs**

  - Route handler helpers
  - Authentication and authorization utilities
  - Data access abstractions

- **Shared APIs**

  - Validation utilities
  - Formatting helpers
  - Configuration and environment resolution

- **Build-time APIs**

  - Strict application/core registry composition
  - Provider and framework artifact planning
  - Resource Studio capability catalogs and descriptor normalization

- **Trace & Diagnostics**

  - Structured tracing
  - Logging utilities
  - Developer diagnostics

- **Authorization (ARBAC)**

  - Protected core catalogs, application composition, and audited core overrides
  - Scoped assignments and identity-provider group adapters
  - Authorizers, decisions, permission patterns, and precedence

- **Type Definitions**
  - Core framework types
  - Request and response contracts
  - Shared domain models

Where applicable, APIs are marked as **Client**, **Server**, or **Shared**.

## How to Use the API Reference

Each API is documented on its own page and follows a consistent structure:

- Description of purpose and behavior
- TypeScript signature
- Parameters and return values
- Usage examples
- Notes and constraints
- Related APIs

This format allows the API Reference to be used as:

- A **lookup resource**
- A **source of truth**
- A **stable contract** between CloudIgniter and application developers

---

## Stability and Compatibility

Unless otherwise stated:

- APIs documented here are considered **public**
- Breaking changes follow semantic versioning
- Experimental APIs are explicitly marked

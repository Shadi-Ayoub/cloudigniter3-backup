# ciResolvePrimaryRole()

Selects the strongest recognized role from a flat role list. This is useful for identity adaptation, display,
and diagnostics; it does not perform ARBAC authorization.

## Signature

```ts
function ciResolvePrimaryRole(
  roles: readonly string[],
  rolePrecedence?: Readonly<Record<string, number>>
): string | null;
```

The default map is `CI_CORE_ROLE_PRECEDENCE`. Matching is case-sensitive, output preserves the canonical
lowercase kebab ID, and lower non-negative finite numbers are stronger. Unknown roles cannot become primary. Equal precedence keeps
the first assigned role.

```ts
ciResolvePrimaryRole(["user", "admin"]); // "admin"

ciResolvePrimaryRole(["viewer", "owner"], { viewer: 50, owner: 10 }); // "owner"
```

Primary role selection does not create inheritance or discard other memberships. The authorizer evaluates all
scoped assignments and applies its configured combining algorithm.

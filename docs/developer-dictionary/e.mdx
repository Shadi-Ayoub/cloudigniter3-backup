## Export Map {#export-map}

The `exports` field in a package manifest that declares its supported import entry points. In CloudIgniter, entries such as `/client`, `/server`, `/lib`, and `/types` communicate intended runtime and API boundaries. Adding a source export is incomplete until the package’s build and export map make the intended entry consumable.

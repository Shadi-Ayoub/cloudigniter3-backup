The CloudIgniter application template uses AWS Amplify Gen 2 to define authentication, data models, and backend
resources in TypeScript. The AWS provider connects these resources to CloudIgniter’s application contracts.
Application-specific infrastructure belongs in `amplify/custom`.

For your first application, complete [AWS preparation](../getting-started/before-you-start) and
[Run the Application Template](../getting-started/run-template) before extending the backend.

Start with [The folder structure](./folder-structure) to understand how Auth, Data, and backend resources are
composed. Then follow [Extending the Amplify backend](../providers/aws/extending-amplify-backend) to register
application resources and configure their permissions. For generated Data Entities and management pages, use
[Resource Studio](../resource-studio/overview).

CloudIgniter owns the core Amplify folders and composition entry points. Add application behavior through the
custom registries and hooks so that template upgrades can preserve your application code.

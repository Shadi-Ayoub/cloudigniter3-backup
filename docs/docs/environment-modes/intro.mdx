CloudIgniter exposes one runtime mode through `CI_ENV_MODE` and, when browser-safe presentation needs it,
`NEXT_PUBLIC_CI_ENV_MODE`. The supported modes are `development`, `test`, `staging`, and `production`.

Environment mode is a capability and deployment signal; it is not authorization evidence and does not
automatically partition records inside one table. Use separate deployments/resources for environment isolation,
then apply normal tenant keys and authorization within each deployment.

Development tools use a stricter rule than ordinary environment branching. Dev Beacon, Debug Probe, and seeders
are available only when the mode is exactly `development`, the actor is authenticated, and the actor has the
exact `developer` role ID. The [development tools and seeding guide](./development-tools-and-seeding) shows the
supported workflow.

# 8. Authenticator Setup

Amplify UI's Authenticator is wrapped with a `ThemeProvider` for consistent look-and-feel (RTL/LTR safe).
Your Authenticator props and style theme are passed from the server-built `PageConfig`, so you can centralize:

- sign-in/sign-up field configuration,
- styling tokens,
- per-environment tweaks.

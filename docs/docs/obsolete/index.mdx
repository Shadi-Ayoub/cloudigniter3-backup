# Obsulete

This section preserves previous-version guidance and superseded drafts. It is separate from the current
application learning path. Every archived page includes a historical notice and a link to its replacement.

Start with [Welcome to CloudIgniter](/docs/intro) for the current guide.

## Preserved page addresses

Archived documents retain their existing addresses so saved links still open with a clear historical notice.
The sidebar places them only beneath this section. Current learning pages, Dictionary definitions, Developers
guidance, and API references link to the appropriate current replacement.

No historical page is evidence that an old import, configuration field, or runtime behavior remains supported.
Check the current API contract before migrating an older application.

This section will describe the set of heavy-lefting components that form the backbone kernel of CloudIgniter. These components were designed to handle the main
features of the system that would make it:

1. Performant
2. Secure
3. Scalabile
4. Developer-centred
5. AWS compliant
6. Customizable
7. Universal

These files are:

- Middleware
- [Authorization (ARBAC)](./authorization/overview)
- cloudigniter.config.ts
- Bootstrap
- kernel
- CloudIgniterRootWrapper
- Layout
- Page
- global-error.tsx
- custom folder
- locale folder

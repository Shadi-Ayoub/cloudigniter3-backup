# Best Practices for Developers

**Do**

- Always pass tenant context explicitly
- Use provided server utilities
- Respect environment constraints
- Treat tenant status as authoritative

**Avoid**

- Hard-coding tenant IDs
- Cross-tenant queries without intent
- Using tenant type as a security mechanism
- Bypassing tenant checks for convenience

Existing package scripts remain aliases for CI, Turbo and developer shortcuts.
Prefer DEV commands in new automation. DEV executes tools directly instead of
calling the same package script recursively.

The `build:dev2` and `build:prod2` aliases have no separate modes. `config-ts` has
no applicable package scripts. Application scripts, documentation commands and
root Turbo orchestration retain their respective owners.

For older Next test scripts, replace the positional test selector with the filter
option documented in [dev package test](/commands/dev/package-test). See
[workspace migration](./workspace.mdx#migrating-from-ci-dev) for the executable and
build-export migration.

**CloudIgniter Users** use `ci`, supplied by the public `@cloudigniter/cli` package,
to work on CloudIgniter applications. Here, a User is an application developer or
operator using the platform, rather than a maintainer of its packages.

The CLI operates against the target application and its installed CloudIgniter
packages. It supports resource generation, application module validation and
Amplify bootstrap/deployment workflows. Consumer applications can use this public
package without installing the restricted company toolkit.

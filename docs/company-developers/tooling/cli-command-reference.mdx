[CloudIgniter Commands](/commands) contains the maintained reference for both
executables. Choose the manual for the development profile and task:

| Profile | Manual | Scope |
| --- | --- | --- |
| CloudIgniter User | [ci Commands](/commands/ci) | Application resources, modules and provider operations. |
| CloudIgniter Developer | [dev commands](/commands/dev) | Company package maintenance, quality, GitHub operations, templates and releases. |

Each command page includes syntax, prerequisites, parameters, effects, examples,
errors and recovery. Common invocation and exit-status conventions are documented
in each executable's overview.

For workflow context, start with the [Developer tooling introduction](./index.mdx),
then continue to [application tooling](./ci/index.mdx) or
[company tooling](./dev/index.mdx). Contributors extending a command should follow
[Command design and extension](./cli-architecture.mdx).

# G


## Generated Resource

An application resource whose artifacts and registry entries are owned by a registered generator. Generated output stays inside declared custom seams, rejects collisions, and is updated or dropped through a confined file transaction.


## Global Scope

An application-wide, cross-tenant authorization boundary. Global scope does not imply CloudIgniter system administration, and system scope does not imply global business access.


## GSI

A DynamoDB Global Secondary Index used for a named query access pattern. A GSI is eventually consistent and must not be used as authoritative proof for a current authorization or lifecycle transition.

# I


## Identity Group

A named collection of users managed by an identity provider, such as a Cognito user-pool group. CloudIgniter's AWS template reads group names from the `cognito:groups` token claim to resolve role IDs, with separate handling for the root identity group. Group membership supplies identity information; the catalog defines privileges and trusted scoped assignments determine where those privileges apply.


## Identity Provider

A service that verifies who is signing in and supplies information about the authenticated account, such as its ID and group memberships. That information can be carried as [claims](/dictionary/c#claim) in a session token. CloudIgniter's Next.js + AWS template uses [Cognito](/dictionary/c#cognito). Provider data is assignment input; it is not proof that an arbitrary Tenant or Org Unit scope is valid.


## Immutable Slug

A stable, URL-safe Org Unit segment that cannot be changed after creation. Moving an Org Unit rewrites its path and descendants while retaining the node’s slug and identity.


## Internationalization

The localization system that resolves locale, text direction, and route-scoped message bundles. Application messages override core messages at matching keys. See [Internationalization](/docs/configuration/localization).

# H


## Handler

A trusted server function that validates an operation, resolves runtime identity and environment, calls the owning service, and returns a standardized response. Provider handlers receive only the permissions and environment bindings their operation requires.


## Hard Delete

See [Purge](/dictionary/p#purge). In CloudIgniter, permanent deletion is separate from ordinary user-facing Delete and is available only after soft deletion through the Trash workflow.


## Hierarchy-aware Authorization

Authorization that evaluates an Org Unit assignment against authoritative predecessor IDs. Descendant access is never inferred from URL segments or client-provided tree state.


## Hydration

The React process that attaches client behavior to server-rendered HTML. CloudIgniter keeps initial output deterministic—for example by using explicit locale/timezone formatting—to prevent server/client mismatches.

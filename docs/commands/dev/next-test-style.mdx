Compile one Next style for focused validation.

## Syntax

```text
dev next test-style [--style=<name>]
```

## Prerequisites

Run from the owning `packages/<name>` directory in the private CloudIgniter workspace after installing its dependencies. `--workspace-root` selects discovery and does not change the current package.

## Parameters

| Parameter | Meaning |
| --- | --- |
| `--style=<name>` | Style directory name; defaults to standard. |

See the [dev common options](./index.mdx#common-options) for workspace selection, diagnostics, help, and version output.

## Remarks and effects

Compiles `src/styles/<name>/style.css` with Tailwind into `tmp.css`. A positional style is supported for compatibility, but cannot combine with `--style`. The complete package build still validates distribution output.

## Examples

```bash
cd packages/next
pnpm exec dev next test-style --style=standard
```

## Errors and recovery

A missing required configuration or tool fails the command. A failed subprocess stops the workflow and returns a nonzero status. Inspect the first reported failure before retrying.

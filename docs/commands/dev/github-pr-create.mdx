Open a pull request from an already-pushed feature branch.

## Syntax

```text
dev github pr create --project=<id|workspace> --head=<branch> --title=<text> --body-file=<path> [--draft]
```

## Prerequisites

Run in the private workspace with [GitHub CLI prepared by DEV](./github-setup.mdx) and the relevant company policies configured. Online commands use the selected named GitHub profile; credentials remain in GitHub CLI storage.

## Parameters

| Parameter | Meaning |
| --- | --- |
| `--project=<id\|workspace>` | Required configured project ID, or workspace for the integration monorepo. |
| `--repository-kind=source\|build` | Defaults to source. workspace has no build repository. |
| `--profile=<name>` | Named GitHub profile; also selected through CLOUDIGNITER_PROFILE. |
| `--head=<branch>` | Pushed feature branch distinct from the configured base. |
| `--title=<text>` | Required PR title. |
| `--body-file=<path>` | Required nonempty UTF-8 description file. |
| `--draft` | Create the PR as a draft. |

See the [dev common options](./index.mdx#common-options) for workspace selection, diagnostics, help, and version output.

## Remarks and effects

Creates a remote PR against the configured base and requests independent configured reviewers. The requester must be authorized. This command does not commit or push your local changes.

## Examples

```bash
pnpm exec dev github pr create --project=workspace --head=feature/docs --title="Improve guides" --body-file=pr.md --draft --profile=developer
```

## Errors and recovery

Missing description, an invalid/unpushed branch, an unauthorized account, or no independent reviewer blocks creation.

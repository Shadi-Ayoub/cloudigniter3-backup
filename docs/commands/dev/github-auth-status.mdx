Inspect GitHub authentication or verify a configured profile.

## Syntax

```text
dev github auth status [--profile=<name>]
```

## Prerequisites

Run in the private workspace with [GitHub CLI prepared by DEV](./github-setup.mdx) and the relevant company policies configured. Online commands use the selected named GitHub profile; credentials remain in GitHub CLI storage.

## Parameters

| Parameter | Meaning |
| --- | --- |
| `--profile=<name>` | Verify this profile; without a flag or environment selection, inspect stored GitHub CLI account status. |

See the [dev common options](./index.mdx#common-options) for workspace selection, diagnostics, help, and version output.

## Remarks and effects

Reports authenticated status without performing login or printing credentials. A selected profile is verified against its configured identity.

## Examples

```bash
pnpm exec dev github auth status --profile=developer
```

## Errors and recovery

Missing credentials or mismatched identities fail; authenticate the intended profile and retry.

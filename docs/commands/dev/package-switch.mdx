Switch package exports and TypeScript mappings between source and distribution.

## Syntax

```text
dev package switch --target=src|dist [--no-interactive]
```

## Prerequisites

Run from the owning `packages/<name>` directory in the private CloudIgniter workspace after installing its dependencies. `--workspace-root` selects discovery and does not change the current package.

## Parameters

| Parameter | Meaning |
| --- | --- |
| `--target=src\|dist` | Required target; may be prompted for interactively. |

See the [dev common options](./index.mdx#common-options) for workspace selection, diagnostics, help, and version output.

## Remarks and effects

Uses `scripts/ci-switch-sources.config.mjs` and optional mappings to rewrite package exports and TypeScript configuration. Review the resulting files before committing.

## Examples

```bash
cd packages/next
pnpm exec dev package switch --target=dist --no-interactive
```

## Errors and recovery

A missing required configuration or tool fails the command. A failed subprocess stops the workflow and returns a nonzero status. Inspect the first reported failure before retrying.
